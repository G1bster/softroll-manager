# SoftRollManager

**SoftRollManager** — це World of Warcraft (WotLK 3.3.5a) аддон для зручного керування лутом за системою Soft Reserve (SR). Він спеціально розроблений для спрощення роботи Рейд Лідерів (РЛ) і гравців під час рейдів. Підтримує таблиці луту для ЦЛК (Icecrown Citadel) та РС (Ruby Sanctum).

## Основні можливості

- **Панель керування рейдом**: Перегляд усіх учасників рейду, їх ролей (Танк, Хіл, ДПС), статусу та лімітів софтів.
- **Список софтів (Реєстр)**:
  - Зручне сортування *по гравцях* та *по босах*.
  - Вбудовані тултіпи (підказки) для всіх предметів.
  - Анонс софтів конкретного боса або окремого предмета в рейд-чат.
- **Оглядач здобичі (Loot Browser)**: Каталог предметів за босами, що дозволяє легко знайти потрібну річ і зробити резерв кліком прямо в інтерфейсі аддону.
- **Роздача луту (Loot Session)**: Спеціальна панель для РЛ-а при роздачі предметів з трупа боса, яка автоматично підтягує гравців, які засофтили ці предмети.
- **Чат-парсер**: Автоматична обробка повідомлень з чату формату `sr [item_link]`, `sr clear` тощо.
- **Ко-Хости (Помічники)**: РЛ може надавати іншим гравцям права на керування сесією софтів.

## Встановлення

1. Завантажте архів з кодом (`Code` -> `Download ZIP`).
2. Розпакуйте архів.
3. Переконайтеся, що папка називається `SoftRollManager` (якщо вона називається `SoftRollManager-main`, перейменуйте її).
4. Перемістіть папку в директорію гри: `Ваша_папка_WoW\Interface\AddOns\SoftRollManager`.
5. Запустіть гру і в списку модифікацій перевірте, чи увімкнений аддон.

## Основні команди гравця (в чат рейду або в ПМ РЛу)

- `sr [Лінк предмета]` — зарезервувати предмет.
- `sr [Лінк предмета] x2` — подвійний резерв (якщо дозволено РЛом).
- `sr list` — перевірити власні софти.
- `sr clear [Лінк предмета]` — скасувати конкретний софт.
- `sr clear` — скасувати всі свої софти.

## Для виклику аддону в грі
Використовуйте кнопку біля міні-карти або команду в чат:
`/sr` або `/softroll`
